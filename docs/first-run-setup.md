# 처음 설정과 진행 상황

대시보드의 **환경 현황**에서 영역별 상태를 본다. 왼쪽 **시작 안내 → 처음 설정**으로 들어가면 기본 6단계의 선택·저장·실행 확인을 안내한다. 평소 각 메뉴에서 설정할 때는 이 단계 안내를 표시하지 않는다.

1. **셸과 테마 선택**: Oh My Zsh·테마를 선택하거나 기본 셸을 유지한다.
2. **필요한 도구 선택**: 필요한 도구만 켠다. 선택은 설치가 아니다.
3. **원격 저장소 접근**: 서버·접속 방식을 정한다. SSH는 기존 설정 사용이 기본이며, 지정 키 공급이 필요할 때만 비밀 관리에서 연동한다.
4. **커밋 작성자·적용 규칙 · 선택**: 필요하면 폴더 규칙을 만들고 앞서 등록한 연결을 지정한다. 작성자 이름·이메일도 지정할 수 있다. 자동 적용이 필요 없으면 설정 없이 확인하고 넘어간다.
5. **선택한 설정 검토·저장**: 초안을 검토한 뒤 설정 파일을 생성한다.
6. **도구 설치·설정 적용·접속 확인**: 적용 안내의 명령을 터미널에서 실행하고 확인한다.

1–4번의 각 화면 위에 있는 **이 선택으로 진행**으로 선택을 확인하고 다음 단계로 이동한다.
모든 기능을 켤 필요는 없다. 필요 없는 기능을 끄거나 연결을 추가하지 않는 선택도 확인할 수 있다.
확인 과정에서 입력이 유효하지 않으면 오류를 표시하고 다음으로 넘어가지 않는다.

5번은 현재 초안이 저장되어 있을 때만 저장됨으로 표시한다. 6번의 configure·새 셸·Git/SSH
접속 확인은 **실행했고 확인했어요**로 사용자가 직접 기록한다. Git/SSH 접속을 선택하지 않으면
그 접속 확인은 요구하지 않는다. 서버에서 확인한 도구 설치 상태는 이 실행 확인과 따로 표시한다.
대시보드가 명령을 자동 실행하거나 실제 서비스 로그인 성공을 추정하지 않는다.

## 기록과 설정 변경

진행 기록은 이 기기의 `~/.config/dotfiles/dashboard/setup-progress.json`에 저장한다.
기존 settings schema와 인증 파일은 바꾸지 않는다. 기록에는 단계·설정 지문·확인 시각만 있으며
키·토큰 값은 없다. 페이지를 새로고침하거나 서버를 다시 실행해도 유지된다.

관련 선택이 달라지면 그 단계의 확인이 유효하지 않게 표시된다. 예를 들어 도구만 바꾸면
셸 선택 확인은 유지한다. 실제 적용 확인은 전체 설정에 연결되므로 설정이 바뀌면 다시 필요하다.
설정이 이전과 정확히 같아지면 그 설정에 남긴 확인 기록이 다시 유효해진다.
완료를 취소하려면 해당 단계의 **확인 취소**를 누른다. 기록은 설정 선택이나 사용자 확인이며
현재 토큰 유효성이나 실행 중인 컨테이너 상태를 뜻하지 않는다.

## 기본 설정 다음의 선택 기능

- **외부 서비스**: Jira·Confluence·Google 로그인과 갱신.
- **프로젝트 실행 환경**: dev-environment와 프로젝트 .devcontainer 구성.
- **원격 개발 PC 연결 · Tailscale**: 이미 준비한 집 WSL 등에 접속할 새 클라이언트 구성.

이 항목들은 기본 6단계 진행률에 포함하지 않는다. Tailscale은 대시보드의 **원격 접속 → Tailscale·집 WSL**에서 설치·로그인·SSH 설정·접속 확인을
진행한다. [상세 안내](tailscale-client-setup.md)를 참고한다. 비공개 dotfiles에서 대상 설정을 불러올 수 있다. 공개 코드에 개인 계정·노드 주소·정책 스냅샷을 복제하지 않는다.

확인한 원본: 비공개 `doh0106/dotfiles`의 `aae3113` (2026-11-07).
문서에는 호스트 복구와 새 클라이언트 접속을 구분하며, 외부 클라이언트 접속·재부팅 후 자동 시작은
아직 미검증이라고 명시되어 있다. 이번 작업에서 그 접속이나 호스트 정책을 변경하지 않았다.

## 화면의 역할과 선택창

왼쪽의 **환경 현황**은 현재 상태를 요약한다. **처음 설정**은 단계 안내와 진행 기록이며,
**변경 검토·적용**은 직접 관리 설정의 검토·저장·적용 방법·실행 확인이다. 서로 독립된
목적지로 제목·메뉴 선택·주소가 바뀌며 브라우저 뒤로 가기도 지원한다. 처음 설정을 통해
각 관리 화면을 열었을 때는 단계 안내가 표시되고, 왼쪽 관리 메뉴로 직접 들어가면 일반
관리 화면을 연다.

현재 화면은 독립된 제목·주소·메뉴 선택으로 표시한다. 변경 사항이 남아 있으면 먼저 검토·저장한 후 저장된 내용의 적용 방법을 보여준다.

Git의 주 메뉴와 처음 설정은 **원격 저장소 접근 → 커밋 작성자·적용 규칙(선택)** 순서다. 공통
키·토큰·비밀번호·공급·연동·비밀 저장소·키 세션은 비밀 관리에서 별도로 관리한다. 기존 SSH 설정 위임에는 별도 비밀 등록이 필요 없다. 폴더 규칙과
인증 참조는 선택된 항목의 주요 내용을 본문에 표시한다. 선택·변경을 누르면 검색 가능한
선택창에서 폴더·작성자·호스트·인증 공급자 등을 비교한다. 키·토큰 값은 표시하지 않는다.

폴더 규칙을 연결에 지정하는 변경은 커밋 작성자·적용 규칙 단계에서 확인하므로 앞선 호스트
연결 확인을 반복하지 않는다. 호스트·전송 방식·사용하는 인증 참조를 바꾸면 연결 확인이
다시 필요하며, 실제 적용 확인은 여전히 전체 설정에 연결된다.
