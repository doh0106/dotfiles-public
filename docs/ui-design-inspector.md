# 대시보드 UI 설계 살펴보기

기본 대시보드의 기능과 화면을 유지하면서 실제로 구현된 배치·표시 대안을 비교한다.
`ui-common-sense`의 `ui-design-inspector` 공통 런타임을 재사용한다.
선택은 현재 브라우저 메모리의 미리보기 상태이며 선호 기록이나 영구 채택으로 저장하지 않는다.

## 실행

카탈로그는 별도 서버나 배포된 URL을 사용한다. 다음은 이 컴퓨터의 로컬 checkout 예시다.
첫 터미널에서 읽기 전용 정적 서버를 연다.

```sh
python3 -m http.server 8767 --bind 127.0.0.1 \
  --directory /Users/dohyun/Developer/p/ui-common-sense/catalog-v4
```

두 번째 터미널에서 대시보드 미리보기를 연다. 다른 기기에서는 checkout 경로와
실제 접근 가능한 카탈로그 URL을 지정한다. 카탈로그 전체를 dotfiles에 복제하지 않는다.

```sh
cd ~/personal/dotfiles
python3 bin/dashboard.py --design-preview \
  --design-catalog-url http://127.0.0.1:8767/
```

일반 `python3 bin/dashboard.py`에는 검사 도구가 표시되지 않는다.
`--design-preview`는 실제 개인 설정 대신 예시 GitHub 연결을 읽고, 실제 인증 상태를
조회하지 않는다. 서버에서 설정 저장과 서비스 인증 실행을 차단한다. 예시 설정 편집과
적용 안내 미리보기는 가능하지만, 안내 명령을 실행하는 기능은 없다.

## 확인하고 비교하기

- **살펴볼 요소**에서 주 메뉴 위치, 연결 목록과 상세, 보조 설명 펼침을 고른다.
- **이 설계의 이유와 다른 안**을 펼치면 적용 위치·맥락·예외·검증 범위와 실제 카탈로그 링크를 볼 수 있다.
- **하나씩 보기**는 다른 결정을 기본안으로 복원한다. **조합해 보기**는 선택을 함께 유지한다.
- **바뀌는 부분 보기**는 해당 화면으로 이동해 실제 영역을 강조한다.
- **기본 구성으로**는 비교 옵션과 비교용 설명 펼침을 복원한다. 편집한 제품 초안은 지우지 않는다.
- 검사 도구는 **닫기** 또는 도구 안에서 Escape로 닫고, 상단 버튼으로 다시 연다.

| 결정 | 기본안 | 구현한 대안 | 카탈로그 ID |
|---|---|---|---|
| 주 메뉴 위치 | 왼쪽 메뉴 | 상단 메뉴 | navigation-findability-primary-navigation-placement |
| 연결 목록과 상세 | 목록에서 상세 열기 | 다른 배치는 미구현 | spatial-adaptive-layout-list-detail |
| 보조 설명 펼침 | 처음부터 표시 | 눌러서 펼치기 | content-information-architecture-supplementary-disclosure |

좁은 화면에서는 기존 화면 선택 메뉴와 한 열 상세 배치를 사용한다. 보조 설명 비교는
환경 개요의 부가 설명에만 적용하며 오류·적용 순서·저장 경고를 숨기지 않는다.
세 결정은 독립적이며 현재 구현안 사이의 추가 의존 조건은 없다.
자동 메뉴 추천과 목록 옆/아래의 병렬 상세 배치는 제안 상태로 표시하며 체험할 수 없다.

## 원본과 검증

페이지 결정의 원본은 `dashboard/design/dashboard-design.js`다. 공통 런타임은 수정 없이
복사했고 출처·해시는 `dashboard/design/UPSTREAM.json`에 기록했다. 제품 어댑터와
미리보기 배치는 각각 `preview.js`, `preview.css`가 소유한다.

2026-11-07에 다음을 확인했다.

- 실제 HTTP: 예시 설정 사용, 적용 안내 생성, 저장·서비스 실행 403, 기존 설정 파일 보존.
- 브라우저: 메뉴·설명 대안 변경과 목록→상세 이동. 단일/조합/기본안 복원.
- 연결 화면은 이후 사용자 요청으로 목록→상세 구조로 변경했다. 과거 상세 위치 비교는 현재 제공하지 않는다.
- 카탈로그 링크의 해당 항목 표시, 모바일 화면 이동, Escape, 키보드 설명 펼침, 가로 넘침 없음.
- 과거 배치 비교 검사와 현재 목록→상세 검사를 구분한다. 전체 조합의 전수 검사는 하지 않았다.

이는 구현 동작의 검증이다. 사용자의 이해도·작업 속도·선호는 확인하지 않았다.

```sh
python3 tests/design_preview.py
python3 tests/dashboard.py
```
